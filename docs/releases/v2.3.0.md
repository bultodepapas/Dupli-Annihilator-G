# Dupli-Annihilator-G v2.3.0

## Executive Summary

`v2.3.0` delivers a **zero-scroll desktop layout redesign** that eliminates vertical scrolling at 1920×1080. The entire UI now fits within the viewport, saving time and reducing friction.

---

## UI Layout Redesign

### Problem

The previous layout forced users to scroll vertically on standard 1080p displays. Four issues compounded:

1. The **WordChecker panel** was a 4th child in a 3-column CSS grid, creating a 2nd row (~150px).
2. The **Update Banner** consumed ~80px permanently in the document flow.
3. The **OutputSection meta block** (app version, backend, license) added ~100px of rarely-needed information.
4. The root `.app` container used `min-height: 100vh`, allowing unbounded vertical growth.

### Solution

| Change | Savings | Detail |
|---|---|---|
| Viewport lock | — | `.app` locked to `height: 100vh` with `overflow: hidden`; `<main>` scrolls internally on small screens |
| WordChecker → collapsible accordion | ~150px | Moved inside the Processing column as a `<details>` element, closed by default |
| Update Banner → dismissible toast | ~80px | Fixed-position overlay (top-right) with close button and slide-in animation |
| Meta block → collapsible `<details>` | ~100px | App info collapsed by default in OutputSection |
| Smaller textarea | ~50px | `min-height` reduced from 130px to 80px (still resizable) |
| Compact telemetry footer | ~35px | Tighter spacing, smaller font, compact progress bar |
| Separator preview meta merged | ~20px | Two lines combined into one inline display |

**Total vertical savings: ~415px** — brings the layout well within the 1080p viewport budget.

---

## Detailed Changes

### Phase 1: Viewport Lock (CSS Foundation)

- `.app`: `min-height: 100vh` → `height: 100vh` + `overflow: hidden`
- `.grid`: added `overflow-y: auto; min-height: 0` for graceful internal scroll on smaller screens
- `textarea`: `min-height` reduced from `130px` to `80px`

### Phase 2: Update Banner → Dismissible Toast

- `UpdateBanner` component now renders with `.toast` class (fixed position, top-right, z-index 1000)
- Added close button (`✕`) with `onDismiss` callback
- New `bannerDismissed` state in `App` — controls toast visibility
- Slide-in animation from right (`@keyframes slideIn`)

### Phase 3: WordChecker → Collapsible Accordion

- `WordCheckerPanel` removed as 4th grid child (eliminated 2nd grid row)
- Processing column now wrapped in `<div className="col-processing">` containing:
  - `ProcessingSection` (existing card)
  - `<details className="accordion">` wrapping `WordCheckerPanel` (closed by default)
- `WordCheckerPanel` component renders a `<>` fragment instead of `<section className="card">` (no duplicate wrapper)
- Native `<details>/<summary>` — zero extra JavaScript for expand/collapse

### Phase 4: Compact OutputSection

- Separator preview meta: two `<div>` elements merged into one inline display with `|` separator
- `.meta` block (app name, backend version, update channel, job_id, license) wrapped in collapsible `<details className="meta-accordion">`, collapsed by default

### Phase 5: Compact Telemetry Footer

- `.telemetry` padding reduced to `10px 14px`
- `.bar-wrap`: height `10px` → `8px`, margin-top `6px` → `4px`
- `.metrics`: min-width `160px` → `140px`, gaps tightened, font `0.88rem` → `0.82rem`
- `.message`: margin `10px` → `6px`

- Drop-in upgrade. No configuration migration required.
- All existing functionality is preserved — this is purely a layout optimization.

- Update notifications are still shown — now as a toast that can be dismissed.
