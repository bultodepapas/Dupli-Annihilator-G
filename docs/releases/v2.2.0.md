# Dupli-Annihilator-G v2.2.0

## Executive Summary

`v2.2.0` adds a **RESET** button to the Mission Report (Summary Screen), allowing users to fully reset the application to its initial state after a completed run — as if it had just been opened — to start a completely new, unrelated task.

---

## New Feature: Reset Button

### What It Does

After a deduplication run completes and the Mission Report is displayed, users can now click **RESET** to return the entire application to its initial startup state. This clears all form inputs, resets the output path to its default, resets the Word Checker panel, and restores the status to "Idle".

### Why It Was Needed

Previously, users had two options after a run:
- **CLOSE REPORT** — Hides the report but keeps all previous form inputs intact.
- **RUN AGAIN** — Re-runs the same job with the same settings.

Neither option provided a clean slate for a completely different task. The RESET button fills this gap.

### How It Works

1. Click **RESET** in the Mission Report footer (between CLOSE REPORT and RUN AGAIN).
2. The application resets:
   - Summary screen is dismissed.
   - Form fields return to defaults (`mode: ram`, `ordering: preserve_first_seen`, `trim: on`, `drop_empty: on`, empty inputs).
   - Output path is re-resolved to the default Desktop location.
   - Word Checker panel is fully reset (path, status, word, result, message).
   - Status message returns to "Idle".

### Technical Details

| Component | Change |
|---|---|
| `SummaryScreen` component | New `onReset` prop and RESET button added to footer button row |
| `App` component | New `resetApp` callback — resets form to `DEFAULT_FORM`, re-resolves output path, clears checker state, dispatches `reset_summary` + `set_message` |
| Localization | All 10 language files updated with `button.reset` key |
