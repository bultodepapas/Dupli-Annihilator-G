# Dupli-Annihilator-G v1.3.4

## Executive Summary
This is the first release published with a fully curated, professional release-notes package.
Version `v1.3.4` is focused on product communication and legal/compliance clarity.

**Scope of this release:**
- Documentation updates (README and product messaging)
- Licensing and commercial-use documentation
- Release note publishing standards

**Runtime impact:**
- No new deduplication engine behavior
- No processing algorithm changes
- No breaking user workflow changes

## What Is New in v1.3.4

### 1) Documentation Quality Upgrade
- Reworked README with clearer value proposition and end-user onboarding.
- Added stronger structure for:
  - product problem/solution framing,
  - feature coverage,
  - architecture overview,
  - CI/CD and release process.

### 2) Licensing and Commercial Clarity
- Added/updated legal documentation:
  - `LICENSE`
  - `NOTICE`
  - `COMMERCIAL_LICENSE.md`
- Clarified business/commercial licensing path for organizations that do not qualify under the baseline small-business terms.

### 3) Professional Release Notes Pipeline
- Release workflow now supports curated notes from versioned files under `docs/releases/`.
- Publishing uses a deterministic notes source (`body_path`) with a fallback template.

## Full Product Capability Catalog (Current Platform)

### Desktop Experience
- Native desktop app built with Tauri + React.
- Drag-and-drop input support plus file picker workflows.
- Clear RUN/CANCEL cycle with telemetry during execution.
- Mission Report screen at completion with:
  - key result metrics,
  - performance diagnostics,
  - stage timeline,
  - warnings and error context,
  - export/copy/open actions.

### Processing Engine
- Modes:
  - `AUTO`
  - `RAM`
  - `DISK`
- Ordering:
  - `preserve_first_seen`
  - `alphabetical`
  - `unordered_fast`
- Disk alphabetical strategies:
  - `fast_bucket_local`
  - `global_perfect`
- Normalization controls:
  - `trim`
  - `drop_empty`
- Separator controls:
  - escaped parsing (`\n`, `\t`, etc.)
  - raw separator mode

### Observability and Reporting
- Live processing telemetry:
  - stage,
  - files done/total,
  - tokens seen,
  - unique tokens,
  - duplicates,
  - throughput,
  - elapsed and ETA.
- End-of-run summary with:
  - reduction and uniqueness ratios,
  - input/output byte data,
  - mode/order/config echo,
  - stage duration breakdown,
  - warnings and diagnostics.
- JSON export and clipboard report copy.

### Updater and Release Operations
- In-app update check and release page flow.
- Install/restart flow when updater payload is available.
- Major-version guard path (manual install messaging).
- CI release protections:
  - version coherence checks,
  - tag reachability from `main`,
  - cross-platform bundle build and asset publishing.

### Internationalization
- UI locale support:
  - `en`, `es`, `fr`, `pt`, `zh-CN`, `hi`, `ar`, `bn`, `ru`, `ur`.
- Includes updated Portuguese localization consistency in the release train.

## Upgrade Notes
- Recommended upgrade path: install `v1.3.4` from GitHub Releases.
- Existing run configurations remain compatible.
- No migration steps required for normal desktop usage.
