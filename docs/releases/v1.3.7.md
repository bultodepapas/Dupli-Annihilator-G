# Dupli-Annihilator-G v1.3.7

## Executive Summary

`v1.3.7` delivers the definitive fix for the silent startup crash on Windows that has affected `v1.3.5` and `v1.3.6`. The root cause was fully diagnosed by running the installed binary directly and capturing the panic output.

---

## Critical Fix: Application Crashes at Launch (Windows)

### Full Root Cause

`tauri-plugin-updater` 2.10.0 deserializes `plugins.updater` into a Rust struct where **`pubkey` is a required `String` field with no `#[serde(default)]` attribute**. Two consecutive releases failed to account for this:

| Version | `plugins.updater` written by CI | Panic message at startup |
|---|---|---|
| v1.3.5 | *(absent)* | `invalid type: null, expected struct Config` |
| v1.3.6 | `{ "active": false }` | `missing field 'pubkey'` |
| **v1.3.7** | `{ "active": false, "pubkey": "" }` | **none — app launches correctly** |

Both earlier versions produced **no visible error on screen** because the release binary uses `windows_subsystem = "windows"`, which suppresses the console. The application simply never opened.

### Fix Applied

`configure-updater.mjs` now writes `{ "active": false, "pubkey": "" }` when the updater signing keys are absent. The empty string satisfies Rust's serde deserializer for the `String` type. When `active` is `false` the plugin never attempts signature verification, so the placeholder value has no effect on behavior.
