# Dupli-Annihilator-G v2.9.8

## Executive Summary

`v2.9.8` is a follow-up patch release focused on release correctness for the desktop distribution path.

The main engine improvements from `v2.9.7` remain the same:

- host-aware `AUTO` mode now uses available system memory plus a lightweight corpus sample,
- the `DISK` preserve path reduces buckets in parallel for the main overlap-heavy workload,
- benchmark and summary telemetry now expose `auto_*` decision metrics.

This patch fixes the Windows NSIS installer configuration so local desktop packaging works again with the current Tauri toolchain.

---

## Fix: Valid NSIS Install Mode

### What changed

- the desktop Tauri config now uses the valid NSIS install mode value `currentUser`,
- the release updater configuration script was updated to emit the same valid value,
- release operations documentation was aligned with the actual Tauri schema.

### Why it matters

The previous release tag used an invalid NSIS value for the current Tauri version, which blocked local desktop bundle generation. `v2.9.8` fixes that release-path regression.
