# Dupli-Annihilator-G v2.6.2

## Executive Summary

`v2.6.2` delivers two targeted improvements: **EPUB files can now be selected via the file picker dialog** (the backend already supported them — the OS dialog simply wasn't exposing them), and **official Linux builds** are now produced and published as first-class release artifacts alongside Windows and macOS.

---

## Bug Fix: EPUB Files Selectable in File Picker

### Problem

`.epub` files were fully supported by the deduplication engine (`epub_reader.rs`) and listed in `COMPATIBLE_EXTENSIONS` since an earlier release. However, the Tauri file-picker dialog in the desktop UI was missing `epub` from its filter list. As a result, the OS file browser would hide `.epub` files and users had no way to select them through the UI.

### Fix

Added `epub` to the `"All supported"` filter extension list and introduced a dedicated `"EPUB"` filter entry in the `pickInputFiles` dialog. Users can now:

- Browse and select `.epub` files via the file picker
- Use the `"EPUB"` filter to show only EPUB files
- Drag-and-drop `.epub` files as before (unaffected)

**File changed:** `apps/desktop/src/main.tsx`

```diff
- { name: "All supported", extensions: ["txt", "csv", "tsv", "log", "pdf"] },
- { name: "PDF", extensions: ["pdf"] },
+ { name: "All supported", extensions: ["txt", "csv", "tsv", "log", "pdf", "epub"] },
+ { name: "PDF", extensions: ["pdf"] },
+ { name: "EPUB", extensions: ["epub"] },
```

## New: Linux Release Artifacts

### What Changed

The GitHub Actions release workflow (`desktop-release.yml`) now builds on **`ubuntu-22.04`** in addition to `windows-latest` and `macos-latest`. Linux builds are fully parallel — a CI failure on one platform does not block the others (`fail-fast: false`).

**Artifacts published:**

| Platform | Formats |
| --- | --- |
| Windows | `.msi`, `-setup.exe` |
| macOS | `.dmg`, `.app.tar.gz` |
| Linux | `.AppImage`, `.AppImage.tar.gz`, `.deb` |

**System dependencies installed on the Linux runner:**

```
libwebkit2gtk-4.1-dev
libayatana-appindicator3-dev
librsvg2-dev
patchelf
```

These are the standard Tauri v2 Linux build requirements.

### Updater support

Signed `.sig` artifacts are produced for all platforms when `TAURI_SIGNING_PRIVATE_KEY` is configured. The in-app updater can deliver Linux updates via `.AppImage.tar.gz.sig`.
